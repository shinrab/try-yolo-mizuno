# 解像度別人物検知・再識別（ReID）品質評価レポート

## 1. 評価概要
本評価では、画像の解像度が「人物検知の成功率」および「人物再識別（ReID）の整合性」に与える影響を統計的に調査しました。

- **評価対象**: 1,004枚のベース画像（全12,936バリアント）
- **評価手法**:
    - 各画像グループの最高解像度（8192px等）を「基準（Reference）」として設定。
    - 基準画像で検知された人物の特徴量（Embedding）と、各低解像度版で検知された人物の類似度を算出。
- **使用モデル**:
    - 人物検知: YOLOv8 (yolo26n.pt)
    - ReID: OSNet (osnet_x1_0)

## 3. 分析と考察

### 3.1 人物検知の限界点
- **検知不可領域**: 解像度が **32px以下** になると、YOLOによる人物検知は完全に機能しなくなります。
- **急激な劣化**: **64px** では検知率が約4.4%まで低下しており、実用的な運用は不可能です。
- **実用ライン**: 安定して人物を検知（検知率80%以上）するには、**1024px以上** の解像度が必要であることがわかります。

### 3.2 ReID（特徴量一致）の安定性
- **識別精度**: 検知さえできれば、**128px** までは基準画像との類似度 **0.92以上** を維持しています。これは、低解像度でも人物の全体的な特徴（服装や体格など）がある程度保持されていることを示しています。
- **特筆事項**: YOLOの確信度は解像度が下がっても微増する傾向（256px付近）がありますが、これは「検知しやすいくっきりとした対象」のみが抽出対象として残るための統計的な偏りと考えられます。

## 4. 結論・推奨設定
人物の自動追跡や再識別を伴うシステムにおいて、以下の設定を推奨します。

- **推奨最低解像度**: **256px以上**
    - 理由: 検知率が60%を維持し、かつReID類似度が0.95以上と非常に高いため。
- **理想解像度**: **1024px以上**
    - 理由: 検知率が80%を超え、安定したシステム運用が見込めるため。
